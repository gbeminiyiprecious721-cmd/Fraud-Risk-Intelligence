Local demonstration only — not a production system

What this page is

This page makes a real HTTP request to a fraud-risk scoring API running locally on this machine (Stage 14 of this project). It is a Stage 15 "Application Integration" exercise for an ML engineering portfolio — not a deployed service and not a commercial product.

The model, its preprocessing, and the API it is served behind were built, evaluated, explained, and assessed for responsible-AI concerns across the preceding stages of this project before any UI existed. This page adds nothing to the model's logic — it only presents, honestly, what the API already returns.

Important: what this score is and is not

Who would actually use a score like this?

    
The intended decision consumer, per this project's own business framing (Stage 1), is a human fraud investigator who uses the score to help decide which transactions to review first, under a limited review capacity — not an algorithm that decides anything on its own.

Running this locally

    
Start the API, then serve this page with a local HTTP server (not file://, so the browser applies real CORS rules):

    
.venv/bin/uvicorn src.api:app --host 127.0.0.1 --port 8000
python3 -m http.server 8080 --directory ui

    
Then open http://127.0.0.1:8080 in a browser.
