    Responsible Use & Limitations

    • This score is an investigation-prioritization signal only — it ranks transactions relative to one another, for a human investigator to triage.
    • It must never be used to automatically decline, block, or flag a transaction as fraud without human review.
    • It is not a calibrated probability — no reliability diagram, Brier score, or recalibration has been performed anywhere in this project.
    • Every record shown on this page is synthetic and portfolio-safe, fabricated for this demo and scored on request — none are real or training transactions.
    • The historical Stage 10 metrics (Model Insights) are a separate, fixed, one-time measurement on held-out data — they describe the model in general, not any specific prediction shown on this page, and must never be read as if they applied to an individual transaction.
    • This project makes no demographic fairness claim; a Responsible AI assessment was performed on the model (Stage 12) but is not re-run or re-validated by this dashboard.
    • This is a portfolio demonstration, not production banking software, and was never evaluated, reviewed, or approved as one.
