# Fraud-Risk-Intelligence

## ML Workflow

This project follows a staged ML workflow. Current state, completed/pending stages,
decisions, and approval status are tracked in `docs/ML_WORKFLOW_STATE.md` — read it
before doing any ML work in this repo, and update it after completing a stage.

Stage work requires explicit per-stage approval from the project owner before
advancing to the next stage. Do not infer approval from "continue"/"proceed" without
a named stage, from a prior session's note, or from a stage being technically possible.
